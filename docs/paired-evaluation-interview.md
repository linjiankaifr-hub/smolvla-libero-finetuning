# SmolVLA 配对评测与项目讲述

本项目让LIBERO中的Panda机械臂读取双相机RGB、8维本体状态和固定任务指令，输出7维末端动作。使用公开示范38条训练、8条验证，冻结视觉语言模型，微调动作专家及相关投影1000次；不声称从零训练基础模型。

## 这轮实际增加了什么

此前基座仅测3回合，微调正式10回合成功9次，另3个开发条件成功1次。本轮固定原权重、输入适配、训练集统计、动作执行窗口和成功判据，新增30个官方初始条件，逐一配对基座和微调模型，分别为0/30与18/30。没有根据本轮测试继续改模型或挑选成功子集。

这轮的价值是把单次微调演示推进到有完整对照的任务评测。数据与动作契约7项通过；源码、模型、统计量和历史记录指纹保持一致。两模型同一任务、同一初始状态、同一推理种子、同一超时；报告同时保留成功、退步及共同失败。

## 必须能回答的追问

1. **9/10和本轮结果为什么不同？** 两组初始条件与种子不同，小样本成绩不能外推所有条件；应分别报告，不能说同一模型在同一测试上退步或直接混算。
2. **基座0成功说明什么？** 只说明使用本任务输入输出适配和训练统计的这个基座在本轮条件下未完成任务，不说明整个基础模型没有机器人能力。
3. **为什么要配对？** 避免模型面对不同难度分配；每个条件同时保留两模型结果，能看到改善和退步，而不是只展示成功视频。
4. **这证明泛化或语言理解了吗？** 没有。任务与指令固定，训练示范和官方初始状态的布局对应关系未完全公开。新评测条件不等于严格训练未见布局。
5. **数据如何防止泄漏？** 按完整回合划分训练／验证，归一化只用训练数据；但这不自动证明仿真测试布局与示范完全独立。
6. **输入输出怎么对应？** 状态是末端位置3、轴角3、夹爪关节2；动作是末端平移3、旋转3、夹爪1。夹爪动作从数据0闭合／1张开转换为环境+1闭合／-1张开。相机输入旋转180度，与示范核对一致。
7. **为什么保存后再加载评测？** 验证保存的权重、配置和归一化足以恢复实际策略；避免仅证明训练进程中临时对象能运行。
8. **区间覆盖什么？** Wilson区间按二项抽样作近似描述，不覆盖训练随机性，也不能保证固定条件列表对所有场景的总体覆盖。
9. **你的贡献和边界？** 按实际参与说明本机数据适配、训练入口、审计、配对评测和结果分析；官方SmolVLA与LIBERO归上游作者，代码由Codex协助完成，没有真机部署。

## 下一轮如何选择

先看共同失败案例的视觉与动作／状态轨迹，区分已观察现象与推测原因。针对数据覆盖或训练预算提出一个问题，用独立开发条件选择方案，再预先固定新的测试协议。不要在这30个已看过的测试条件上反复调参后宣称独立提升。

源码复核：data_pipeline.py管数据与动作约定，policy_utils.py管模型加载及归一化，evaluate.py管重置／推理／判定，analysis中的报告与公开核验脚本管配对和证据。完整数字以实验报告和逐回合记录为准。
